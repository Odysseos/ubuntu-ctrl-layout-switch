# Выбор раскладки одиночным отпусканием клавиши

Ubuntu 24.04 / GNOME 46 / Wayland; два источника: US и RU. Поддерживаются несколько клавиатур и произвольная пара разных клавиш из Ctrl, Shift, Alt, Windows/Super с любой стороны. Fn не поддерживается.

## Запуск

Из папки комплекта, обычным пользователем графической сессии:

```bash
./install.sh
./disable.sh
./enable.sh
./uninstall.sh
```

Shell-скрипты напрямую вызывают `ctrl-layout.py` через `/usr/bin/python3`. Переносите всю папку. sudo перед командой не нужен: системные операции сами запрашивают пароль.

## Выбор клавиш и клавиатур

1. Запустите `install.sh`.
2. На вопрос о первой раскладке нажмите и отпустите нужную клавишу, например правый Shift.
3. На вопрос о второй раскладке нажмите и отпустите другую клавишу на той же клавиатуре, например левый Alt.
4. Клавиатура определится автоматически. На вопрос о настройке другой клавиатуры ответьте «да» и выберите на ней её собственные первую и вторую клавиши.
5. Когда список готов, ответьте «нет».

Заранее вводить имена клавиш или передавать параметры не требуется. Повтор той же клавиши на втором шаге отклоняется с просьбой выбрать другую. Неподдерживаемые клавиши и сочетания не выбираются. Фиксация происходит после полного нажатия и отпускания.

Подтверждение всегда показывает `[y/N · д/Н]` и принимает `y/yes/n/no` и `д/да/н/нет` без учёта регистра. Enter означает «нет». Определение языка через Xwayland удалено: в Wayland-сессии наблюдалась неверная подсказка, а её точная причина не подтверждена.

При повторном `install.sh` выберите пару на той клавиатуре, которую хотите изменить или добавить. Только её назначение обновится; остальные устройства сохранят свои пары. Исходная резервная копия не заменяется. `enable.sh` включает сохранённую конфигурацию без диалога выбора. Ctrl+C отменяет выбор и восстанавливает ранее работавшую службу.

## Поддерживаемые назначения

| Физическая клавиша | Имя keyd | Слой при удержании |
|---|---|---|
| Левый / правый Ctrl | leftcontrol / rightcontrol | control |
| Левый / правый Shift | leftshift / rightshift | shift |
| Левый Alt | leftalt | alt |
| Правый Alt | rightalt | altgr |
| Левая / правая Windows, Super | leftmeta / rightmeta | meta |

Правый Alt сохраняет функцию AltGr. Одиночное нажатие Windows используется для раскладки вместо обычного одиночного действия Super; сочетания должны сохранять функцию модификатора. Подтверждение на реальной системе ранее получено для Ctrl; другие модификаторы проверены автоматически на уровне конфигурации и требуют проверки своих сочетаний в приложениях.

Fn исключена из поддерживаемых клавиш: эксперимент не заработал на практике. Установщик отклоняет её при выборе.

## Механизм

keyd преобразует одиночное отпускание выбранной первой/второй клавиши в F13/F14 через `overload`. XKB назначает `ISO_Next_Group` только в той группе, из которой нужно уйти; в уже нужной группе используется `VoidSymbol`. `NoAction()` предотвращает самостоятельное изменение группы XKB. Mutter передаёт переключение GNOME Shell, который обновляет источник и индикатор вместе.

Опция `grp:menu_toggle` включает штатный обработчик Mutter. Наш файл возвращает Menu обычное действие. CapsLock не меняется. Расширение Input Source Binder не нужно; уже установленное расширение скрипты не удаляют. Задержек, unsafe mode и дополнительных фоновых служб нет.

## Установка, сохранение состояния и откат

При необходимости устанавливается keyd из PPA `keyd-team/ppa`. Нужны системные Python 3 и python3-gi. Источники становятся US и RU; старые `grp:*` заменяются, остальные XKB-опции сохраняются. Источники и конфигурация XKB общие, но пара клавиш у каждого устройства своя. Например: внешняя — левый/правый Ctrl, встроенная — левый Ctrl/правый Shift.

Посторонние пользовательские файлы XKB не перезаписываются. Активный старый тест распознаётся и переносится с его резервной копией. При потере истории точное совпадение с известной конфигурацией позволяет принять текущее состояние как исходное для будущего удаления. Состояние старой установки через Input Source Binder требует удаления старым комплектом.

- `disable.sh` удаляет все управляемые конфиги клавиш, возвращает исходные XKB-файлы, источники и опции; сохраняет состояние для включения.
- `enable.sh` восстанавливает сохранённый набор клавиатур с индивидуальными парами.
- `uninstall.sh` дополнительно возвращает первоначальный конфиг keyd, если он существовал. Поэтому старое переключение может вернуться.
- keyd и PPA остаются установленными; чужие конфиги сохраняются. При отсутствии других конфигов удаление восстанавливает исходное состояние службы.
- Ручные изменения управляемых файлов и настроек останавливают автоматическую перезапись.

Состояние: `~/.local/state/ctrl-layout/state.json`; после удаления — `removed.json`. Учитываются XDG_STATE_HOME и XDG_CONFIG_HOME. Отсутствие отключённой внешней клавиатуры не мешает работе встроенной. Если другой способ подключения меняет ID, добавьте его отдельно.

Скрипт `install-gnome-first-layout-at-login.sh` независим: его правило относится к сессии, а не к клавиатуре или выбранным клавишам.

## Ограничения и ручная проверка

Нужны ровно две XKB-раскладки. Каждая клавиатура получает собственный конфиг keyd и отдельное состояние модификаторов. Удержание модификатора на одном устройстве при вводе на другом отдельно не проверено. При заранее зажатой другой клавише последующее нажатие выбранного модификатора может считаться одиночным — ранее принятое ограничение overload. Работа на лок-скрине отдельно не подтверждена.

Выберите US через меню GNOME после установки. Проверьте на каждой клавиатуре: вторая клавиша дважды оставляет RU, первая дважды оставляет US; удержание не переключает; сочетания с выбранными модификаторами работают; после смены языка через меню ввод и индикатор согласованы.

## Код и тесты

`ctrl-layout.py` содержит `main()` и функции настройки, проверки и диалога. Импорт не подключается к D-Bus и не запускает системные команды. Подробная ручная настройка и история альтернатив — в `MANUAL.md`.

```bash
/usr/bin/python3 -m unittest discover -s tests -v
```

Тесты используют настоящий модуль, временные каталоги и заглушки команд/GSettings. Проверяются установка и откат, разные устройства, интерактивный выбор и запрет одинаковых клавиш, все поддерживаемые пары, отклонение Fn, монитор и диалог на псевдотерминале. Интеграционные тесты компилируют XKB через libxkbcommon. sudo, работающий keyd и подключение к GNOME не нужны; системная раскладка не меняется.

## Файлы для отдельных клавиатур

Управляемые файлы имеют вид `/etc/keyd/ctrl-layout-046d-b35b-794355b5.conf`: один ID и одна пара в каждом файле. При переносе старой общей настройки `ctrl-layout.conf` убирается из активных конфигов, а его исходное содержимое остаётся в резервной копии. Формат состояния теперь имеет версию 3; `enable.sh` и `uninstall.sh` также понимают прежнее состояние. Существующие посторонние файлы с совпавшим именем не перезаписываются. Удаление возвращает исходную общую конфигурацию, если она была до установки.
