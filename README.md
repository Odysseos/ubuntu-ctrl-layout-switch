# Ctrl → выбор раскладки: Ubuntu 24.04, GNOME 46, Wayland

Четыре shell-скрипта напрямую вызывают общий `ctrl-layout.py` через системный `/usr/bin/python3`. Они запускаются обычным пользователем из терминала графической сессии. Не ставьте sudo перед командой: необходимые системные операции сами запрашивают пароль.

```bash
./install.sh
./disable.sh
./enable.sh
./uninstall.sh
```

## Установка

Скопируйте всю папку на другую систему, включая `ctrl-layout.py`. Установщик при необходимости устанавливает keyd из PPA `keyd-team/ppa`. Требуются стандартные для Ubuntu Desktop Python 3 и python3-gi. На первой установке скрипт сам запускает `keyd monitor`: нажмите и отпустите левый, затем правый Ctrl на одной клавиатуре. ID не зашиты в код; каждое устройство определяется отдельно. После определения каждой клавиатуры установщик спрашивает, добавить ли ещё одну. Повторный запуск install.sh показывает сохранённые ID и позволяет добавить клавиатуры; enable.sh просто включает сохранённый набор без вопросов.

Устанавливаются ровно два источника: английский US и русский RU. Прежние источники сохраняются. Предыдущие XKB-опции `grp:*` временно заменяются; остальные опции остаются. Посторонние rules/evdev и symbols/ctrl_layout не перезаписываются. Если сохранённое состояние потеряно, но файлы точно совпадают с нашим решением, текущая конфигурация принимается как исходное состояние для будущего удаления. Существующий конфиг Ctrl принимается только при совпадении с ожидаемым назначением.

Активный `ctrl-layout-conditional-test` переносится автоматически: сохраняются его исходные настройки, а его backup.json переименовывается в migrated-to-v2.json. После переноса управляйте решением этими четырьмя скриптами, не старым тестом. Старую установку через Input Source Binder, если она отмечена как установленная, сначала нужно удалить старым комплектом.

После установки выберите английскую в меню GNOME и проверьте ввод и индикатор. Перелогин для активации не требуется.

## Механизм

keyd выдаёт F13/F14 при отпускании одиночного Ctrl. При сочетании с другой клавишей сохраняется Ctrl. XKB задаёт ISO_Next_Group только в той группе, из которой нужно уйти; в уже выбранной группе используется VoidSymbol. Действие NoAction не позволяет XKB самостоятельно менять группу. Mutter обрабатывает ISO_Next_Group, а GNOME Shell переключает источник и индикатор вместе.

Опция grp:menu_toggle включает штатный обработчик Mutter. Пользовательский файл возвращает клавише Menu обычное значение Menu; CapsLock не меняется. Расширения, Eval/unsafe mode, дополнительные фоновые службы и задержки не используются. Input Source Binder не требуется; ранее установленное расширение скрипты не удаляют и не включают.

## Отключение и удаление

- disable.sh убирает конфиг Ctrl и пользовательские XKB-файлы, возвращает исходные источники и XKB-опции. Состояние сохраняется для enable.sh.
- enable.sh повторно включает решение без повторного определения клавиатуры.
- uninstall.sh также возвращает прежний конфиг Ctrl, если он существовал до установки. Поэтому прежнее переключение через Input Source Binder может снова работать. Для прекращения любого переключения одиночными Ctrl используйте disable.sh.
- keyd и его PPA остаются установленными: это общие зависимости, которыми могут пользоваться другие конфигурации. Чужие конфиги keyd сохраняются. При отсутствии других конфигов удаление восстанавливает исходное состояние службы.
- Ручные изменения управляемых файлов, источников и опций вызывают остановку с объяснением, а не молчаливую перезапись.

Состояние и резервные копии: `~/.local/state/ctrl-layout/state.json`; после удаления — `removed.json`. Учитываются XDG_STATE_HOME и XDG_CONFIG_HOME.

## Ограничения

Проверено для Ubuntu 24.04 / GNOME 46 / Wayland и двух XKB-раскладок. При заранее зажатой другой клавише последующее отдельное нажатие Ctrl может считаться одиночным — ранее принятый предел keyd overload. Работа на экране блокировки отдельно не подтверждена. Другие конфиги keyd не должны перехватывать то же устройство.

## Проверка

Правый Ctrl дважды: RU остаётся RU. Левый дважды: EN остаётся EN. Пока Ctrl удерживается, переключения нет. Ctrl+C/V работают. После выбора раскладки через меню GNOME оба Ctrl продолжают выбирать нужную. Проверяйте и ввод, и индикатор.

## Несколько клавиатур

Запустите `./install.sh`. На первой установке нажмите и отпустите оба Ctrl на внешней клавиатуре, ответьте «д» на предложение добавить ещё одну, затем повторите на встроенной и ответьте «н». Если внешняя уже настроена, она остаётся в списке: ответьте «д» и определите встроенную. Дубликаты игнорируются. Ctrl+C отменяет сбор; ранее работающая служба запускается снова.

Все выбранные ID записываются отдельными строками в одну секцию `[ids]`. Клавиатуры используют одинаковое назначение Ctrl и общее состояние keyd. Отключённая внешняя клавиатура не мешает работе встроенной; подключать внешнюю требуется для её первоначального определения, но не для каждого enable.sh. Если при другом способе подключения устройство получает другой ID, добавьте его отдельно.

Отключение применяется ко всему набору. Удаление восстанавливает первоначальный конфиг целиком; добавление клавиатур не перезаписывает исходную резервную копию. Скрипт первого языка при входе менять не нужно: его правило относится к сессии, а не к клавиатуре.

Подтверждение принимает `y/yes/n/no` и `д/да/н/нет` без учёта регистра; Enter означает «нет». Перед каждым выводом вопроса скрипт читает текущую группу XKB через Xwayland: для US показывает `[y/N]`, для RU — `[д/Н]`. Если определить язык нельзя, показывает оба варианта. Уже выведенная строка при последующем переключении языка не перерисовывается; ответы на обоих языках всё равно принимаются.

## Структура Python-кода

`ctrl-layout.py` содержит точку входа `main()`, отдельные функции проверки окружения и подготовки установки, управления конфигурацией и диалога с пользователем. Импорт модуля не подключается к D-Bus и не запускает системные команды. Формат сохранённого состояния и команды shell-обёрток сохранены.

## Автоматические тесты

Из папки комплекта:

```bash
/usr/bin/python3 -m unittest discover -s tests -v
```

36 тестов импортируют настоящий `ctrl-layout.py`. Проверяются конфигурации нескольких клавиатур, защита ручных изменений, сохранение состояния, установка/отключение/удаление, перенос старого теста и принятие конфигурации без истории, откат при ошибке компиляции или перезагрузки keyd, обработка событий монитора и отмены, язык подсказки и ответы на псевдотерминале. Два интеграционных теста компилируют правильную и намеренно испорченную XKB-таблицу через libxkbcommon.

Используется стандартный unittest: pytest не нужен. Зависимости — системный Python 3 с python3-gi, libxkbcommon и Linux-псевдотерминал. Тестам не нужны sudo, работающий keyd или подключение к сессии GNOME: системные команды и GSettings заменяются заглушками, файлы создаются во временных каталогах. Интеграционные тесты XKB не изменяют раскладку сессии. Сквозная проверка физической клавиатуры и индикатора остаётся ручной.
